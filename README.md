# ✨ StyleSphere – Fashion & Lifestyle Website

### Discover Your Style, Define Your Story.

## 🌸 Project Overview

StyleSphere is a multi-page fashion and lifestyle website developed to bring fashion inspiration, styling ideas, and the latest trends together in one place.

The website focuses on creating a clean, visually appealing, and user-friendly experience where users can explore fashion trends, discover different styles, and find inspiration for their everyday looks.

## 🎯 Key Features

- **Fashion Discovery:** Explore different fashion trends and styles.
- **Style Guide:** Discover outfit ideas and styling inspiration.
- **Trend Exploration:** Browse modern fashion and lifestyle trends.
- **Multi-Page Navigation:** Seamlessly navigate between four interconnected web pages.
- **User-Friendly Design:** Simple layout with structured content and easy navigation.

## 🛠️ Technologies Used

- HTML5 – Website structure and semantic elements.
- CSS3 – Styling, layout, and visual presentation.

## 📂 Project Structure

- `index1.html` – Home Page
- `index2.html` – Second Page
- `index3.html` – Third Page
- `index4.html` – Fourth Page
- CSS files – Styling and layout.
